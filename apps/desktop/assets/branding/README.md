# Aivora 品牌图标资源

当前品牌方向：A 形光棱、深夜蓝底、电光青与极光紫高光。

## 四套资源

1. `aivora-wordmark.svg`：主 Logo，包含图形标志和 Aivora 字标。
2. `aivora-app-icon.svg`、`aivora-app-icon-*.png`：应用图标，适合启动页、Dock、任务栏和安装包。
3. `aivora-mark.svg`、`aivora-mark-*.png`：透明背景小尺寸图形标志，适合导航栏、菜单栏和状态区域。
4. `aivora-monochrome.svg`、`aivora-monochrome-*.png`：单色版本，适合打印、浅色背景和低彩度场景。

Electron 当前使用：

```text
assets/icons/win/aivora.ico
```

PNG 资源包含 16、24、32、48、64、96、128、256、512 和 1024 像素版本。SVG 是可编辑母版，后续调整品牌图形时优先修改 SVG，再重新导出 PNG/ICO。
