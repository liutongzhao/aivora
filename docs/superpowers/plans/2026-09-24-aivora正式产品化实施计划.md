# Aivora 正式产品化实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 Aivora 改造成连接本地后端、具备正式视觉和完整交互的 AI 工作台，并验证截图到答案的真实闭环。

**Architecture:** 保持 FastAPI 模块化单体 API + Celery Worker + Redis Streams + MinIO + Next.js Web + Electron Desktop。先统一本地连接和共享数据协议，再建设视觉系统和页面，随后补齐题型提示词、结构化答案与端到端测试。

**Tech Stack:** Python 3.12、FastAPI、SQLAlchemy、Flyway、PostgreSQL、Redis、Celery、MinIO、OpenAI 兼容 API、Next.js 15、React 19、TypeScript、Socket.IO、Vitest、Testing Library、Playwright、pytest、原生 CSS 动画。

**Spec:** `docs/superpowers/specs/2026-09-24-aivora正式产品化设计.md`

## Global Constraints

- 当前分支保持为 `main`，每次切换分支必须更新 `AGENT.md`。
- Git 提交使用英文分类前缀和中文说明。
- 后端、Worker、Electron、Web 启动和停止只操作本项目的 screen 会话。
- 本地 API 使用 `http://127.0.0.1:18000`。
- 本地 Web 使用 `http://127.0.0.1:3000`。
- Electron 的网络地址全部从统一配置读取，不保留旧远程域名作为业务调用地址。
- MinIO 是截图和文件的唯一持久化入口。
- 不增加积分、账单、支付、邀请和增长功能。
- 管理后台只保留 `admin` 一个管理员角色。
- 页面必须提供加载、空数据、错误、成功、禁用和键盘焦点状态。
- 动画使用 CSS transition/keyframes，必须支持 `prefers-reduced-motion`。
- Web 开发服务运行期间不执行 `npm run build --prefix web`，避免 `.next` 缓存冲突。
- 不把 API Key、`.env.local` 或本地服务密钥写入 Git。

## Review Focus

- 浏览器登录后 API 使用 Cookie Session，Electron 使用 `X-Session-Id`，两种认证方式不能互相泄露权限。
- Web 开发服务和生产构建不能同时写入 `.next`，重启后页面必须能稳定打开。
- AI Provider 返回非法 JSON 或中途断流时，用户仍能看到原始答案和明确警告。
- SSE 断线后带 `Last-Event-ID` 重连不能重复追加内容，也不能跳过最终状态。
- MinIO、Redis 或 Worker 不可用时，任务必须进入可解释的失败状态。

```ts
const API_BASE = process.env.NEXT_PUBLIC_API_BASE_URL ?? "http://127.0.0.1:18000";

export async function apiFetch<T>(path: string, init: RequestInit = {}): Promise<T> {
  const sessionId = window.localStorage.getItem("aivora_session_id");
  const response = await fetch(`${API_BASE}${path}`, {
    ...init,
    credentials: "include",
    headers: {
      "Content-Type": "application/json",
      ...(sessionId ? { "X-Session-Id": sessionId } : {}),
      ...(init.headers ?? {}),
    },
  });
  const body = await response.json().catch(() => ({}));
  if (!response.ok) {
    const detail = body?.detail;
    throw new Error(typeof detail === "string" ? detail : detail?.message ?? "请求失败");
  }
  return body as T;
}
```
