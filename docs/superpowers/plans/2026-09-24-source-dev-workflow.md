# 源码开发启动链路 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 让恢复出的 Aivora 源码支持本地开发启动、类型检查、生产构建和构建产物启动。

**Architecture:** Vite 提供 React 前端开发服务器和生产构建；TypeScript 将 Electron 主进程编译到 `dist-electron`；Electron 在开发模式读取 `ELECTRON_RENDERER_URL`，生产模式读取 `dist/index.html`。`concurrently` 和 `wait-on` 负责组合开发进程。

**Tech Stack:** Electron, React, Vite, TypeScript, `@vitejs/plugin-react`, `concurrently`, `wait-on`.

**Spec:** `docs/superpowers/specs/2026-09-24-source-dev-workflow-design.md`

## Global Constraints

- 开发服务器端口固定为 `54321`。
- 不改变现有业务功能、窗口行为、远程接口或题型处理逻辑。
- `npm run dev` 必须启动 Vite、Electron 主进程编译监视和 Electron 应用。
- `npm run build` 必须生成 `dist/index.html` 和 `dist-electron/main.js`。
- `npm run start` 必须从构建产物启动 Electron。

## Review Focus

- Electron 启动时开发服务器尚未就绪：必须由 `wait-on` 保证加载顺序。
- 开发模式的 URL hash：必须保留 `#/overlay`、`#/login` 和 `#/config`。
- 生产模式路径：必须从 `dist/index.html` 加载，而不是依赖开发服务器。
- TypeScript 输出路径：必须让 `preload.js` 和 `main.js` 位于 Electron 现有路径约定中。
- 原生音频助手路径：开发模式和打包模式都不能破坏现有候选路径探测。
